# 수학 수업 허브 · Math Atelier

중등 수학 교사를 위한 로컬 우선 웹앱입니다. 프로그램 주소를 카드로 관리하고 타이머·무작위 번호 뽑기·모둠 편성·동전/주사위 실험·좌표/일차/이차함수 그래프를 사용합니다.

## 바로 실행

Node.js가 설치된 PC에서 `실행.cmd`를 더블클릭한 뒤 콘솔에 표시된 주소를 브라우저에서 여세요.

```powershell
cd "path\to\math-class-hub"
npm.cmd run preview
```

주소: http://127.0.0.1:4175/ · 서버는 이 PC에만 연결됩니다. 종료는 콘솔에서 Ctrl+C입니다. 최초 접속은 실행 중인 서버가 필요합니다. ‘오프라인 준비 완료’ 이후에는 같은 주소·브라우저에서 기본 도구를 캐시로 실행할 수 있습니다. `dist/index.html`을 직접 더블클릭하는 file:// 실행은 지원하지 않습니다.

GitHub 소스에는 `dist/`가 없습니다. 최초 실행 전 `npm.cmd ci --ignore-scripts --no-fund`와 `npm.cmd run build`를 실행하세요. 브라우저 우측 메뉴에 설치 기능이 제공되는 환경에서는 PWA로 설치할 수 있습니다. 학교의 설치 정책은 별도로 확인해주세요.

## 수정 및 검증

프로젝트는 React 19.3.1, TypeScript 7.0.2, Vite 8.3.4로 구성했습니다. Vite의 Node 요구사항은 ^20.19.0 또는 >=22.12.0이며, 제공한 TypeScript 테스트는 Node 24에서 검증했습니다. Node 24 사용을 권장합니다.

```powershell
npm.cmd ci --ignore-scripts --no-fund
npm.cmd run dev
# 수정 후
npm.cmd run build
npm.cmd test
# preview가 실행 중일 때
node scripts/verify-http.mjs
```

`npm test`의 오프라인 테스트는 빌드된 Service Worker를 사용하므로 처음에는 `npm run build`를 먼저 실행하세요. `npm run dev`는 개발용이며 오프라인 준비를 하지 않습니다. 설치 시 lifecycle 스크립트를 차단했고 잠금 파일을 보관했습니다. 설치·변경 시에는 취약점과 라이선스를 다시 검토해야 합니다.

## 사용 방법

- **프로그램 등록:** 이름·설명·HTTPS 주소 입력. 웹앱은 새 탭에서 엽니다. 개인정보나 토큰을 넣지 마세요. 안전한 기본 주소 사용을 위해 쿼리(?)·해시(#)·URL 인증정보는 허용하지 않습니다.
- **타이머:** 초 단위 입력 또는 1·3·5·10분 선택 → 시작 → 일시정지·재개. 제시 모드에서 큰 숫자를 보여줍니다.
- **번호 뽑기·모둠:** 학생 수와 제외 번호 입력 → ‘대상 적용·저장’ → 실행. 제외 번호는 다음 수업 전에 확인하세요. 중복 방지가 켜진 뽑기는 회차 초기화로 다시 시작합니다.
- **확률 실험:** 동전 또는 주사위와 반복 횟수 입력 → 실행. 표와 막대그래프에 횟수·상대도수를 표시합니다.
- **좌표·함수:** 점의 x·y 또는 함수 계수 입력 → 추가/그리기. 표시 범위는 ±1~1,000입니다. 표에서 점 삭제와 함수값 확인이 가능합니다.
- **전체화면:** 제시 모드 버튼 → Esc 또는 ‘나가기’로 복귀. 전체화면 거부 시 창 안에서 확대합니다.
- **초기화:** 설정에서 수업 설정·외부 등록 목록을 각각 지우거나 전체 초기화합니다. 확인창에서 취소하면 유지됩니다. 기본 도구와 오프라인 파일은 삭제하지 않습니다.

## 저장과 오프라인

학생 수·제외 번호·타이머 기본값·외부 등록 목록은 localStorage에 저장합니다. 이름·명부·성적·출결 이력을 수집하지 않습니다. 번호도 학생과 연결하면 식별 가능하므로 명부나 개인정보를 결합하지 마세요. 결과·점·함수 계수·진행 중 타이머는 메모리에만 있고 화면 이동/재시작 때 사라집니다.

같은 브라우저 프로필 사용자는 자료를 볼 수 있습니다. 암호화된 개인정보 보관소나 계정 접근 제어를 제공하지 않습니다. 브라우저 데이터를 삭제하면 설정도 사라지며, 동기화·백업은 없습니다. 저장 실패는 안내하고 수업 설정은 해당 세션에 임시 적용합니다. 등록 목록 저장 실패 시 폼과 이전 목록을 유지합니다. 손상/알 수 없는 버전은 원본을 보존하고 명시적 초기화 전 저장을 잠급니다.

오프라인 캐시는 허브와 기본 수업 도구의 필수 정적 파일만 포함합니다. 모든 파일이 준비돼야 완료로 표시합니다. 외부 앱과 다른 작업에서 추가된 `pdf-counter`는 이 캐시의 대상이 아닙니다. 업데이트는 새 파일 준비 후 사용자 확인을 받아 적용하고 기존 설정을 유지합니다. 진행 중 활동에는 강제 적용하지 않습니다. 이전 캐시는 기존 세션 보존을 위해 자동 삭제하지 않으며 저장 공간 제한에 도달하면 새 버전 준비 실패를 안내합니다.

## 구조

| 파일 | 역할 |
|---|---|
| `src/App.tsx` | 허브·등록·설정·확인창·제시 모드 |
| `src/Tools.tsx` | 다섯 가지 도구 화면 |
| `src/core.ts` | 숫자·주소·대상 검증, 난수·편성·실험·그래프 계산 |
| `src/storage.ts` | 버전 검증·손상 자료 보호·저장 예외 처리 |
| `src/offline.ts` | 오프라인 준비와 업데이트 상태 |
| `src/style.css` | DESIGN.md를 반영한 다크·구리색 UI |
| `scripts/build-sw.mjs` | 빌드 파일·워커 코드 해시 기반 캐시 생성 |
| `scripts/serve.mjs` | 루프백 전용 정적 미리보기·보안 헤더 |
| `tests/` | 계산·저장 무결성·캐시 실패 테스트 |
| `AUDIT.md` | 검증 결과와 제한 |

`public/pdf-counter`와 관련 카드·서버 경로는 개발 중 다른 작업에서 추가되어 보존했습니다. 이 문서의 핵심 도구 검증 범위에는 포함하지 않습니다.

## 일기장

허브의 **하루의 기록 · 일기장** 카드는 `/diary/`를 엽니다. `실행.cmd` 또는 `npm run preview`로 실행하세요. 개발용 Vite 서버에서는 일기장 API를 제공하지 않습니다.
Node.js 24 이상이 필요합니다. 기록은 형제 폴더 `../일기장/data/diary.sqlite`에 암호화하여 저장하며, 허브 설정 초기화로 지워지지 않습니다.
비밀번호 설정과 백업·복구 방법은 [일기장 사용 설명](../일기장/README.md)을 참고하세요. 허브 폴더를 옮길 때는 형제 `일기장` 폴더도 함께 옮겨야 합니다.

## 배포 전 확인

실제 공개 배포는 수행하지 않았습니다. HTTPS 정적 호스팅에 `dist/`를 제공할 수 있으며 하위 경로도 상대 경로로 빌드합니다. 호스팅에서 `scripts/serve.mjs`와 같은 CSP·MIME·Referrer 정책을 구성하고 SW의 갱신 정책을 확인하세요. 실제 학교 PC·프로젝터 가독성·기관 정책·호스팅 접속 로그 정책은 확인이 필요합니다.

이 프로젝트의 보안 점검은 전문 보안 감사나 학교·교육청의 운영 승인을 대체하지 않습니다.

## 저장소 구성

PDF 도구 소스는 이 저장소의 public/pdf-counter/에 있으며 PDF 개발 도구 저장소는 같은 상위 폴더의 pdf-letter-counter로 복제하세요. 일기장은 별도 비공개 저장소입니다. 권한이 있는 사용자만 해당 저장소를 같은 상위 폴더의 일기장 폴더로 복제할 수 있습니다. 일기장 없이도 허브는 실행되며 일기장 카드는 사용할 수 없습니다. 실제 일기 DB는 저장소에 포함되지 않습니다.
